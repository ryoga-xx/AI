# 営業活動OS

営業報告、見込み顧客、返信テンプレートをまとめて扱う、インストール可能なPWAです。スマートフォンやPCのホーム画面／アプリ一覧から起動でき、初回に読み込んだ後はオフラインでも画面を開けます。

## 起動

PWAとして使うにはHTTPSで配信してください（`file://` からはインストールできません）。開発用には作業フォルダで `python3 -m http.server 8000` を実行して `http://localhost:8000` を開けます。スマートフォンに追加する場合はHTTPSで公開したURLを開き、iPhoneはSafariの共有メニューから「ホーム画面に追加」、Android／デスクトップChromeはブラウザメニューから「アプリをインストール」を選びます。

GitHub Pagesで公開する場合は、`main` ブランチへ反映後に Actions の `Deploy GitHub Pages` が完了すると `https://ryoga-xx.github.io/AI/` で開けます。初回のみ、GitHubのリポジトリ設定で Pages のSourceが `GitHub Actions` になっている必要があります。

入力内容はブラウザの `localStorage` に保存されます。保存先は端末・ブラウザ・サイトURLごとに異なります。今の `file://` 版で作成したデータは、インストール前に「報告履歴」からJSONを書き出し、インストールしたPWA側でJSONを読み込んでください。ブラウザのデータを消す前にもJSONを書き出してください。

## できること

- MTG前・アポ後・フォロー後の報告作成、入力中の自動保存、報告文生成、生成後の直接編集、保存、複製、コピー
- 月別見込みの顧客追加・編集・削除、ステータス変更、ドラッグ移動、今日の予定確認、LINE貼り付け用コピー
- 返信テンプレートの追加・編集・削除・検索・カテゴリー絞り込み、変数置換と回答コピー
- 報告履歴のキーワード検索、種類絞り込み、再編集、コピー、削除、JSONバックアップと復元
- アポ後／フォロー後報告での録音再生、文字起こしテキスト・TXT/VTT/SRT読込、対応ブラウザのマイク入力、文字起こし内容の反映、話題別の要点抽出・編集・報告欄への反映
- 初期サンプルデータ：2026年10月見込み7名、10/5 MTG前報告、ハナダ シホのフォロー後報告

データはサーバーに送信されません。複数端末間の同期、ログイン、クラウドバックアップはMVPの対象外です。

この構成はホーム画面に追加できるPWAです。App Store／Google Playで配布するネイティブアプリのパッケージや、一般公開用のHTTPSホスティングは含みません。

音声ファイルの文字起こし自体はブラウザ内では実行せず、音声の再生と、文字起こしテキストの読込・マイク入力を提供します。録音ファイルの自動文字起こしや自然な文章を生成するAI要約には、別途外部サービスの接続が必要です。現状の要点整理は文字起こし内の文をキーワードで分類する方式で、内容を推測して補いません。
